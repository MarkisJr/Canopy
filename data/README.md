# Personal data folder

This is the recommended place for your exported Canopy JSON backups if you keep them beside the
app. The JSON files in this directory are ignored by Git; this README remains tracked.

Canopy cannot force Firefox, Safari, and Chromium to open a particular folder in the Save As
window. Choose this directory when exporting and your browser may remember the last-used location,
or configure the browser's download settings to ask where each file should be saved.
